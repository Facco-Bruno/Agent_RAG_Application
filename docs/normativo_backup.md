# Normativo de Backup

Define a estratégia de cópia de segurança para dados críticos.

| Tipo de Backup | Frequência | Retenção |
| -------------- | ---------- | -------- |
| Completo       | Diário     | 30 dias  |
| Diferencial    | 4h         | 7 dias   |
| Off‑site       | Semanal    | 90 dias  |

Procedimentos de restauração devem ser testados trimestralmente.
